# 🏠 부동산금융 실습 계산기 (Streamlit)

단국대학교 도시계획·부동산학부 부동산금융 수업용 예제 앱입니다.

- ① 대출 상환 계산기: 원리금균등·원금균등·만기일시 상환 비교
- ② DSR 점검: 연소득 대비 원리금 상환 비율과 규제 한도 비교 (교육용 단순 계산)
- ③ 임대 투자수익률: NOI, Cap rate, 자기자본수익률, 금리 × 공실률 민감도 분석

## 로컬 실행

```
pip install -r requirements.txt
streamlit run app.py
```

※ 이 앱의 계산은 수업용 단순 모형이며, 실제 대출 심사·규제 기준과 다를 수 있습니다.
